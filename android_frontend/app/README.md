# Personal Notes Organizer - Android App

Features:
- Notes list with last-modified sorting
- Create, edit, and delete notes
- Local offline persistence via lightweight SQLiteOpenHelper (no Room/KSP required)
- Ocean Professional theme (primary #2563EB, secondary #F59E0B, error #EF4444)
- Modern UI with rounded corners, subtle shadows, and smooth interactions

Build:
- Uses Declarative Gradle DSL with the Android ecosystem plugin
- No KSP/annotation processors required
- Standard AndroidX/Material dependencies
